Descargas

    Problemas frecuentes

    No se pudo instalar o no encuentro ffmpeg

    ffmpeg es el programa que convierte a MP3 y une el video con el audio. Descárgalo desde ffmpeg.org/download.html o instálalo con un comando:

    Macbrew install ffmpeg
    Windowswinget install -e --id Gyan.FFmpeg
    Linuxsudo apt install ffmpeg

    Después cierra el descargador y vuelve a abrirlo.

    No encuentro yt-dlp

    yt-dlp es el programa que baja el video de YouTube. Mira las instrucciones oficiales o usa un comando:

    Macbrew install yt-dlp
    Windowswinget install -e --id yt-dlp.yt-dlp
    Cualquierapython3 -m pip install -U yt-dlp

    Después cierra el descargador y vuelve a abrirlo.

    YouTube pide iniciar sesión o confirmar la edad

    La app reintenta sola con las cookies del navegador donde abriste esta página, así que necesitas tener la sesión de YouTube iniciada ahí.

    Detecta Chrome, Edge, Firefox, Safari y Opera. Brave y otros navegadores se ven como Chrome y puede fallar, así que mejor abre esta página en uno de los detectados.

    No pude leer las cookies del navegador

    Depende del navegador y del sistema:

    • Mac, Chrome o Edge: piden la contraseña del llavero. Elige «Permitir siempre».
    • Mac, Safari: dale a Terminal «Acceso total al disco» en Ajustes del Sistema, Privacidad y seguridad.
    • Windows, Chrome o Edge: ciérralos del todo, porque bloquean el archivo de cookies.
    • Firefox: suele funcionar sin pasos extra.
    YouTube rechazó la descarga

    YouTube cambia seguido y yt-dlp necesita estar al día. Actualízalo:

    Macbrew upgrade yt-dlp
    Windowswinget upgrade yt-dlp.yt-dlp
    Otrosyt-dlp -U
